## Engineering
Use client-only lazy-loaded 3D scenes; shared scene state and deterministic transitions, scroll and buttons, touch-safe interactions. Responsive layout for iPhone and desktop; reduced motion and WebGL failure fallback. Optimize textures, cap DPR, pause offscreen rendering, dispose GPU resources, avoid autoplay video/audio with sound. Use local demo assets, no third-party trackers. Production private media in authenticated storage or server-gated routes; never put private files in public/ or Git. Access code hashed, rate limiting, secure HttpOnly SameSite cookies, HTTPS, no indexing (not a substitute for authentication), no cache leakage. Use environment variables, document setup. QR links to approved stable HTTPS entry, not a secret in URL.
