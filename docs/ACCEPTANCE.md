# Milestones and acceptance
M1: scaffold, design tokens, local launch, mobile layout, asset manifest, placeholder data. Document npm install/dev/build commands.
M2: envelope, star journey, reveal, camera transitions, replay, reduced motion and WebGL fallback. Local preview before further work.
M3: gallery with touch/keyboard controls, modal, captions, photo/video loading, 2D fallback; test with placeholders and then private originals.
M4: astronomy verification, map, letter, capsule, audio, certificate and finale. Record source URLs, epoch and time assumptions. No official naming claim.
M5: private access and storage; test unauthorized requests to every private asset, brute-force controls, session expiration, cache behavior. No private assets in build/public/Git. Test mobile Safari and desktop Chromium; report actual results, not assumed passes.
M6: six print PDFs, visual proof against approved reference, dimensions/bleed/font checks. QR placeholder until deployment.
M7: user approves local experience; only then deploy, test live HTTPS and QR on phone, regenerate final PDFs, package final deliverables and instructions.
Every milestone: run lint/typecheck/build and relevant automated tests; report commands, results, screenshots, known issues and changed files. No fake screen recording. If browser capture available, provide actual video or screenshots; otherwise explain limitation. Avoid endless loops and unnecessary dependencies.
